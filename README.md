# Secure Data Wiping System — Premium Flask UI

A final-year project version of a secure data wiping system with a modern single-page Flask interface, progress tracking, logs, and certificate generation.

## Features
- Single-page premium dashboard
- Project branding area
- Screenshot showcase area for viva/demo
- Folder path input with safety checks
- Multi-pass secure wipe: 1, 3, or 7 passes
- Live progress polling
- Activity logs page
- PDF certificate generation

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open:
```bash
http://127.0.0.1:5000
```

## Demo advice
Create a separate sample folder with dummy files and test only on that folder.
Never point the app to a real system folder.
